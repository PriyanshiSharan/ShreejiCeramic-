# Shree Ji Ceramic Portal

A premium web-based product catalog and quotation system for Shree Ji Ceramic.

## Features
- Interactive product selection (Aquant & Kohler)
- Real-time quotation builder
- High-end luxury UI with glassmorphism and animations
- Fully responsive design

## Deployment
This project is ready to be hosted on **GitHub Pages** or **Vercel/Netlify**.
Simply push the contents of this directory to a GitHub repository.
